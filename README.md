# 分贝记录仪

基于 Python + 麦克风的实时声音监测工具，界面显示声音高低（分贝值）、彩色量程条、60 秒历史曲线和统计信息，可导出日志与图表。

## 文件说明

| 文件 | 作用 |
|---|---|
| `decibel_meter.py` | 主程序（分贝记录仪） |
| `启动分贝记录仪.bat` | 双击即可运行（Windows） |
| `.venv/` | 项目虚拟环境（已装好依赖） |

## 运行方式

- 方式一（推荐）：双击 `启动分贝记录仪.bat`
- 方式二：命令行执行 `.venv\Scripts\python.exe decibel_meter.py`

## 界面功能

1. **麦克风选择**：下拉框列出电脑所有输入设备，可切换任意麦克风（如 AULA G9、Realtek 阵列、VB-Audio 虚拟声卡等）
2. **曲线时长**：选择历史曲线的记录时长（30秒 / 1分钟 / 3分钟 / 5分钟 / 10分钟），决定曲线窗口和“平均/最低”统计范围
3. **记录上限**：选择最大记录总时长（不限 / 1分钟 / 5分钟 / 10分钟 / 30分钟 / 1小时），到点自动停止并提示统计结果
4. **抽样方式**：曲线显示的时间片聚合方式，监测中可随时切换——**最高值**（抓峰值）/ **平均值**（看整体）/ **平均+最高/2**（两者折中）；只影响显示，全量原始数据始终保留
5. **计量单位**：dBFS（相对分贝，默认）/ 百分比%（响度百分比，-60dB=0%→0dB=100%）/ dB SPL（声压级估算，可设校准偏移）；大数字、量程条、统计、曲线、日志全部同步换算，内部始终按 dBFS 记录原始数据
6. **SPL 偏移**：选择 dB SPL 后可输入校准偏移（默认 0），建议对照已知声源校准（如手机分贝 App 读数）——例如手机测得 60dB 而本软件显示 -30 时，偏移设为 90
4. **开始/停止监测**：点击开始后实时采集，状态栏显示已记录时长/剩余时长
5. **大数字分贝显示**：当前音量 + 颜色状态（绿=安静 → 黄=交谈 → 橙=大声 → 红=极响）
6. **彩色量程条**：-60 ~ 0 dBFS 范围，带区间标注和红色峰值保持刻度
7. **历史曲线**：所选时长内的分贝变化曲线，含参考阈值虚线
8. **统计面板**：当前 / 峰值(3秒) / 平均(窗口) / 最低(窗口) / **会话最大** / **会话最小**（从点击开始监测起持续跟踪）
9. **停止监测不清空**：停止后界面保留最后一次读数、曲线和统计，可继续查看或保存
10. **清空按钮**：手动重置全部数据（历史曲线、统计、会话最大/最小、日志缓冲），监测中点击则清空后继续记录
11. **日志记录**：勾选后每秒记录一行数据到内存，可一键导出 CSV（含时间戳、会话最大/最小）
12. **保存图表**：将当前曲线导出为 PNG 图片

## 分贝参考范围（相对值 dBFS）

| 区间 (dBFS) | 描述 |
|---|---|
| < -50 | 安静 |
| -50 ~ -35 | 轻声 |
| -35 ~ -25 | 正常交谈 |
| -25 ~ -15 | 大声 |
| -15 ~ -5 | 很吵 |
| > -5 | 极响 |

## 重要说明

- 显示的是**相对分贝值（dBFS）**，基于麦克风灵敏度，**未经声压级（SPL）校准**。不同麦克风的增益不同，读数会不一致，适合观察声音**相对大小和变化趋势**，不代表真实的“分贝（dB）”声压值。
- 如果读数整体偏低/偏高，可以在 Windows 声音设置中调节麦克风音量/增益来适配显示范围。

- Python 3.14（本机已装）
- 依赖库（已装入 `.venv`）：`sounddevice`（麦克风采集）、`numpy`（计算）、`matplotlib`（绘图）
